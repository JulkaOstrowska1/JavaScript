1. Pętla for

Konstrukcja:

for(zmienna; warunek; zmiana)
{
instrukcje;
}

Pętla wykonuje określoną liczbę powtórzeń.

2. Pętla while

Konstrukcja:

while(warunek)
{
instrukcje;
}

Najpierw sprawdzany jest warunek, później wykonywany jest kod.

3. Pętla do...while

Konstrukcja:

do
{
instrukcje;
}
while(warunek);

Najpierw wykonywany jest kod, a dopiero potem sprawdzany jest warunek.
