dzis = new Date() -> tworzy nowy obiekt daty i czasu
dzis = dzis.getHours() -> pobiera aktualną godzinę
dzis = dzis.getMinutes() -> pobiera aktualne minuty
dzis = dzis.getMonth()+1 -> pobiera aktualny miesiąc (+1 ponieważ miesiące są numerowane od 0)
dzis = dzis.getDate() -> pobiera aktualny dzień miesiąca
dzis = dzis.getFullYear() -> pobiera aktualny rok
